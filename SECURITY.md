# Security

This tool runs models locally and prints a speed scoreboard. It sends nothing anywhere — no telemetry, no accounts.

- Do not post API keys, Ollama remote URLs with credentials, or full local paths in a public issue. Redact usernames from pasted scoreboards.
- Report a bug that executes unexpected commands or exfiltrates the prompt through GitHub private vulnerability reporting. Include the OS version, Python version, and the exact command you ran.
- Supported release: the latest `main`.
